# Film Veritabanı Projesi

Bu proje, Oracle SQL kullanılarak hazırlanmış ilişkisel bir film veritabanı projesidir. Projede filmler, yönetmenler, oyuncular, türler, kullanıcılar ve kullanıcı değerlendirmeleri veritabanı tabloları üzerinden yönetilmektedir.

## Proje Amacı

Bu projenin amacı, film verilerinin düzenli bir veritabanı yapısında saklanmasını sağlamak ve filmler ile yönetmen, oyuncu, tür ve kullanıcı değerlendirmeleri arasındaki ilişkileri SQL sorguları ile yönetebilmektir.

## Kullanılan Teknolojiler

- Oracle SQL
- SQL Developer
- Git
- GitHub

## Veritabanı Tabloları

Projede kullanılan temel tablolar:

- Film
- Yonetmen
- Oyuncu
- Tur
- Kullanici
- Degerlendirme
- Film_Oyuncu
- Film_Tur

## Proje İçeriği

- Film bilgileri
- Yönetmen bilgileri
- Oyuncu bilgileri
- Film türleri
- Kullanıcı bilgileri
- Kullanıcıların filmlere verdiği puanlar
- Film-oyuncu ilişkisi
- Film-tür ilişkisi

## Kurulum

1. Oracle SQL Developer uygulamasını açın.
2. Önce tablo oluşturma komutlarının bulunduğu `schema.sql` dosyasını çalıştırın.
3. Daha sonra veri ekleme dosyalarını çalıştırın.
4. Son olarak örnek SQL sorguları ile veritabanı üzerinde listeleme ve analiz işlemleri yapılabilir.

## Örnek Kullanım Alanları

Bu veritabanı ile şu işlemler yapılabilir:

- Filmleri listeleme
- Yönetmenlere göre film arama
- Oyuncuların oynadığı filmleri görüntüleme
- Türlere göre film filtreleme
- Kullanıcıların verdiği puanları analiz etme
- Ortalama puana göre filmleri sıralama
